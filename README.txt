في بيتنا — أنشطة التواصل

التعديل في النشاط الثاني «أستكشف البيت» فقط:
- طفلة عُمانية كرتونية بالزي الوردي البسيط، وشعر أسود بضفيرتين دون حجاب.
- تكون حزينة قليلًا أثناء انتظار الطلب، ثم تبتسم وتصفّق عند وضع الغرض الصحيح في مكانه.
- تبدأ الأغراض الثلاثة متباعدة على الأرض أمام الطاولة.
- التفاحة في الصحن، والماء على سطح الطاولة قرب الطفلة، واللعبة في الكرتون.
- يسمع المستخدم تسجيل الطلب الأصلي. بعد نجاح التوصيل يسمع تسجيل التشجيع الأصلي ويظهر «أحسنت».
- لا تعزيز عند الإفلات على الوجه أو في الوجهة الخطأ. يعود الغرض إلى موضع البداية عند الإفلات خارج الوجهة.
- يمكن السحب أو لمس الغرض ثم موضع التسليم. زر ⌖ يعيد زاوية النظر.
- وضع تقليل الحركة في الجهاز يستبدل التصفيق المتكرر بصورة الفرح الثابتة.
- الصور والتسجيلات الأصلية محفوظة، وكذلك كود النشاطين الأول والثالث.

النشر على GitHub Pages أو Netlify:
فك الضغط وارفع index.html وmain.js وstyles.css ومجلدَي images وsounds معًا.
يجب أن يظهر index.html في جذر مجلد النشر. لا حاجة لتثبيت مكتبات أو تنفيذ بناء.
في Netlify ارفع المجلد بعد فك الضغط. وفي GitHub Pages اختر الفرع main والمجلد root.
هذه الحزمة لا تتضمن تعديل المستودع المنشور تلقائيًا.
